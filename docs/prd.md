## 1. 市场机会与产品定位

### 1.1 为什么做
- **苹果生态已验证的高客单价品类**：Infuse 在 iOS/macOS 凭「WebDAV/SMB 直连 + 自动刮削海报墙 + 全格式解码」做到年费 ¥98 / 终身买断 ¥648，核心用户（NAS 玩家、影视发烧友、网盘囤片党）付费意愿极强。
- **鸿蒙电脑（HarmonyOS PC）的 100 万台生态缺口**：鸿蒙桌面端初期专业级本地/网络影音播放器极度稀缺，缺少像 Infuse / IINA / PotPlayer 那样兼具颜值与强悍内核的标杆工具。
- **纯血鸿蒙刚需痛点**：系统自带视频应用仅面向本地基础格式（MP4/MOV 等），不支持 WebDAV/SMB、不支持 MKV 内封 ASS 特效字幕、不支持 DTS/AC3/多音轨切换与刮削海报墙；同时大量用户反感 Infuse 的高价订阅制。

### 1.2 核心差异化
1. **三端一包自适应（Phone + Tablet + 2in1）**：同一账号买断，手机通勤看片、平板床上追剧、鸿蒙 PC 键鼠+大屏观影无缝接续。
2. **国内网盘友好（Alist/OpenList + 生态盘）**：不仅支持标准 WebDAV / SMB，还对 Alist 聚合网关（阿里云盘、夸克、115、百度网盘等）做专项优化（302 重定向缓存、直链并发限流保护、目录增量刷新）。
3. **一次性买断定价（¥38–¥68）**：避开“年费订阅焦虑”，用远低于 Infuse 的价格收割纯血鸿蒙第一批高净值 NAS/网盘用户。

## 3. 目标用户与核心场景

1. **NAS / HomeLab 用户**：家中群晖/威联通/飞牛 fnOS/Unraid 部署了电影剧集库，通过内网 SMB 或外网 HTTPS WebDAV 随时远程串流，要求 4K HEVC 不卡顿、保留多音轨和外挂字幕。
2. **网盘 Alist 重度用户**：通过 Alist / OpenList 挂载夸克、115、阿里云盘，在手机/平板/鸿蒙电脑上直接点播原画，不想下载占用本机存储。
3. **鸿蒙电脑（2in1）桌面观影用户**：将本地磁盘或移动硬盘中的 MKV/BDMV 资源拖入播放器，使用方向键快进、空格暂停、快捷键切换字幕/倍速，获得接近 IINA/PotPlayer 的桌面体验。

## 4. 功能范围（P0 = 6–8 周上线必需；P1 = v1.1；P2 = v1.2+）

### 4.1 P0：核心播控与媒体库（Week 1–8）

#### A. 媒体源接入与文件管理
- **本地文件**：`DocumentViewPicker` 导入目录/文件、本地沙箱管理；鸿蒙 PC 支持文件拖拽入窗及系统“打开方式”关联（`.mp4` `.mkv` `.mov` `.ts` `.avi` `.flv` `.webm`）。
- **WebDAV（HTTP/HTTPS）**：支持自定义端口、路径前缀、自签名证书信任开关（局域网 NAS 刚需）、Basic/Digest 认证、连接测试。
- **SMB v2/v3**：手动添加主机/共享名/账密 + mDNS/NetBIOS 局域网设备自动发现（可开关）。
- **Alist 专项适配**：自动跟随 302 跳转并短时缓存直链（避免同一片源 Seek 时频繁触发网盘风控 QPS 限制）。

#### B. 播放内核（C++ NDK）
- **格式与编码**：封装支持 MKV、MP4、MOV、TS、M2TS、FLV、AVI、WEBM；视频硬解 H.264/HEVC/AV1（10bit HDR），软解兜底；音频支持 AAC、MP3、FLAC、OPUS、AC3/EAC3、DTS（软解转 PCM 输出）。
- **流式缓存与 Seek**：基于 HTTP `Range` 的环形预读缓冲区（可配置预读 32MB–128MB），支持弱网断线重连与秒级 Seek。
- **字幕系统**：
  - 内封字幕流自动识别（ASS/SSA、SRT、VTT、PGS 图形字幕）；
  - 同目录同名字幕自动挂载（`.ass`/`.srt`/`.vtt`）+ 手动加载本地/WebDAV 字幕；
  - `libass` 特效渲染、字体 fallback（内置思源黑体兜底，防止中文乱码方块）、字幕延时微调（±0.1s 步进）、大小/位置/描边设置（纯文本字幕）。
- **音轨与画面调节**：多音轨切换、音频延时微调、0.5x–4.0x 倍速（保持音调）、画面比例（适应/填充/16:9/21:9/4:3）、硬件/软件解码一键切换、亮度/对比度/饱和度基础调节。
- **系统播控**：接入 `AVSession`（锁屏/控制中心/鸿蒙 PC 媒体键控制）、后台音频续播开关、防息屏与屏幕锁定。

#### C. 媒体库与海报墙
- **智能文件名解析**：识别电影名/年份/剧集 `S01E02` / `第02集` / `EP02` 等常见命名，自动聚合同一部剧的季与集。
- **元数据刮削**：
  - 优先读取同目录 `.nfo`（兼容 Emby/Jellyfin/Kodi 格式）与本地海报（`poster.jpg`、`fanart.jpg`）；
  - 缺失时调用 TMDB API（支持用户自定义代理/API Host 与语言偏好 `zh-CN`），本地 `RelationalStore` + 磁盘缓存图片，支持手动“重新匹配”。
- **观影记录**：继续观看列表（精确到秒的断点续播）、已看标记、自动跳过片头/片尾（手动设置固定秒数）。

#### D. 三端自适应 UI 与鸿蒙 PC 深度适配
- **手机端（`sm`）**：底部 Tab（媒体库 / 文件源 / 正在观看 / 设置），单手竖屏/全屏手势（左半屏亮度、右半屏音量、横向滑动精确 Seek、长按 2x 倍速）。
- **平板端（`md` / `lg`）**：左侧可折叠导航栏 + 大网格海报墙，播放页支持悬浮窗/画中画与分屏。
- **鸿蒙 PC 端（`2in1`）**：
  - 桌面级布局：常驻侧边栏（媒体库/片源/最近播放/设置）+ 顶部搜索栏 + 悬浮右键菜单；
  - 完整键盘快捷键：`Space` 播放/暂停、`←/→` 快退/快进 5s（`Shift`+方向键 30s）、`↑/↓` 音量、`F` 全屏、`Esc` 退出全屏、`[` / `]` 倍速、`S` 切换字幕、`A` 切换音轨、`I` 媒体信息 OSD 浮层；
  - 鼠标交互：滚轮调节音量、双击切换全屏、顶栏窗口控制（最小化/最大化/置顶/无边框影院模式）、拖拽视频文件或字幕文件进窗口直接加载。

### 4.2 P1（v1.1，上架后 2–4 周迭代）
- **跨端同步与接续**：
  - 基于华为云数据库（CloudDB）或 WebDAV 隐藏配置目录（`.harmonyplayer/sync.json`）同步片源配置（加密）与播放进度；
  - 分布式流转（`Continue`）：手机看到一半靠近鸿蒙平板/电脑一键接续播放。
- **网盘原生 OAuth 直连**：阿里云盘 OpenAPI、115/夸克官方或合规授权接入，减少用户自行部署 Alist 的门槛。
- **在线字幕搜索**：接入 Shooter/SubHD 等公开字幕源搜索与一键下载匹配。
- **HDR Tone Mapping（HDR → SDR）**：针对不支持高亮度 HDR 的普通屏幕做色彩映射优化，避免画面发灰。

### 4.3 P2（v1.2+，生态扩展）
- **Emby / Jellyfin / Plex 媒体服务器直连模式**（直接复用服务端已刮削的海报墙与转码能力）。
- **音频直通与外接 DAC 优化**、高码率局域网测速工具。
- **家庭共享与儿童锁**（分级/目录 PIN 码锁）。

## 6. 合规与上架红线（必守）

1. **ICP 备案**：因使用 `ohos.permission.INTERNET` 请求 WebDAV 与 TMDB，必须完成鸿蒙应用 ICP 备案（建议 Week 0 启动）。
2. **版权与内容合规**：
   - 应用定位为**纯本地与用户自有私有云/NAS/网盘协议播放器**；
   - **严禁**内置任何影视聚合源、盗版站点爬虫、解析接口或推荐片源清单；
   - 首次启动与添加源页面明示免责声明，仅解析用户主动配置的服务器与本地文件。
3. **隐私合规**：
   - 首启隐私政策弹窗未同意前，禁止发起任何网络请求、局域网 mDNS 扫描或获取设备标识符；
   - WebDAV/SMB 账号密码使用系统 `HUKS`（Universal Keystore）加密存储，不上传开发者服务器。
4. **开源协议与解码专利边界**：
   - FFmpeg 编译严格使用 **LGPL** 配置（禁用 `--enable-gpl` 的 x264/x265 编码器等，仅启用解码/解封装或动态库规范分发并在「关于-开源许可」完整展示协议）；
   - 视频解码优先调用系统 `OH_AVCodec` 硬解，减少软解专利暴露面与功耗。
