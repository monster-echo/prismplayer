# 棱镜播放器 PrismPlayer 隐私政策

**生效日期：2026 年 11 月 20 日**
**适用应用：棱镜播放器（PrismPlayer，包名 `tech.zhongbei.prismplayer`）**
**运营者：苏州终北科技有限公司**

---

## 1. 我们的定位

棱镜播放器是一款**本地与私有云视频播放应用**。我们不运营任何影视内容服务器，不内置片源，也不提供在线影视点播服务。你播放的所有影片都来自你自己填写的 NAS、WebDAV、SMB、Plex、Emby、AList、S3、IPTV 或本机文件。

因此，**我们不会收到你的影片文件、片源账号密码，也不会建立你的观看档案**。

## 2. 我们处理的信息

### 2.1 片源地址与凭据（仅存本机）

你添加片源时填写的服务器地址、用户名、密码、Token，通过系统硬件级密钥库（HUKS，AES-256-GCM，带 AAD 认证标签）加密后保存在本机应用沙箱内。

- 不会上传到我们的服务器（我们没有服务器）；
- 仅在建立连接时由本机直接发送给你填写的目标服务器；
- 卸载应用即随沙箱一起删除。

### 2.2 播放与观看记录（仅存本机）

播放进度、最近观看、字幕与音轨偏好、画面比例等，保存在本机数据库中，用于「继续观看」和跨端接续。你可以在「最近观看」中逐条删除，或清除应用数据。

### 2.3 购买信息（由华为处理）

Pro 买断通过**华为应用内支付（IAP Kit）**完成。支付流程、订单与发票由华为负责，我们**不接触你的银行卡、支付账号或账单地址**。本机只保存买断等级（`free / 早鸟 / 个人 / 家庭`）用于解锁功能。

### 2.4 设备与诊断信息（仅存本机）

解码失败、代理连接异常等运行日志保存在本机，用于你在「设置 → 隐私安全与开源许可」中排查问题。我们不上传、不采集。

### 2.5 你主动选择的文件

导入本地视频、选择外挂字幕时，应用仅读取你在系统文件选择器中明确选中的文件，不扫描其他目录。

## 3. 系统权限与用途

- **网络访问**（`ohos.permission.INTERNET`）：连接你填写的片源、TMDB、字幕源与华为支付；拒绝后无法播放网络片源。
- **网络状态**（`ohos.permission.GET_NETWORK_INFO`）：判断是否在局域网，决定直连还是走代理；拒绝后网络诊断降级。
- **跨端接续**（`ohos.permission.DISTRIBUTED_DATASYNC`）：手机与平板/电脑之间继续播放；拒绝后不影响本机播放。

应用不申请通讯录、短信、定位、麦克风、相机权限。

## 4. 第三方服务

只有在对应功能被触发时，才会向下列第三方发起请求。请求中**不包含**你的账号、设备标识或片源凭据。

- **华为 IAP Kit**：你点击购买 Pro 时，由华为完成支付与恢复购买，发送商品 ID 与华为账号（由系统处理），目的是完成支付。
- **TMDB**：你配置 API Key 并启用刮削时，发送影片名称与年份，用于获取海报、简介、季集信息。
- **SubDL / OpenSubtitles**：你搜索外挂字幕时，发送影片名称、季集与语言，用于检索字幕。
- **Bilibili / 抖音**：你粘贴对应平台链接时，发送该公开视频的页面地址，用于解析可播放直链。
- **你填写的片源服务器**：浏览目录、播放、刮削时，凭据与该次请求路径直接发往你自己的媒体库。

上述第三方各自适用其隐私政策。我们不向其提供你的身份信息，也不与其共享观看记录。

**本应用不含广告 SDK、统计 SDK、推送 SDK、崩溃上报 SDK。**

## 5. 存储地点与保留期限

- 全部数据存储在你的设备本地应用沙箱内；
- 我们不设云端副本，因此不存在「跨境传输」；
- 保留期限：直到你删除对应数据或卸载应用；
- 卸载应用会删除应用沙箱内的全部数据（包括加密凭据与播放记录）。

## 6. 你的权利

- **查看与更正**：在「片源管理」「最近观看」中直接查看和修改；
- **删除**：删除单条记录、删除片源、清除应用数据；
- **撤回授权**：在系统「设置 → 应用 → 棱镜播放器 → 权限」中关闭任一权限；
- **停止处理**：卸载应用即停止全部本地处理。

由于我们不在服务器侧保存你的个人信息，我们无法（也无需）为你提供「账户注销」——本应用没有账号体系。

## 7. 安全措施

- 凭据使用 HUKS 硬件密钥加密，密钥不出安全环境；
- 内置的 Range 代理仅监听 `127.0.0.1`，不对局域网或公网开放；
- 与片源之间优先使用 HTTPS；自签名证书需你手动开启信任。

## 8. 未成年人

本应用不面向 14 周岁以下儿童单独提供服务。若你是未成年人，请在监护人同意与指导下使用，并由监护人负责片源内容的合法性。

## 9. 政策更新

本政策变更时，我们会在应用内「隐私政策」入口更新生效日期；涉及处理目的、信息类型或共享对象的重大变更，会在应用内以弹窗方式再次征得你的同意。
